# Книжный сомелье — скилл проекта

Помогает развернуть «Книжный сомелье» локально и работать с ним: запуск,
сценарии проверки, структура кода, типовые доработки.

## Что за проект

Flask-сервис: пользователь описывает запрос («навязчивый детектив с юмором,
не Кинг») — ИИ-агент разбирает его на признаки вкуса, ищет кандидатов в
Open Library и Google Books, отбирает 5 книг с обоснованием и сохраняет
историю в SQLite. Веб-интерфейс: форма → карточки-подборка → история.

## Развёртывание с нуля

1. Скопируйте проект в свою папку (клон с GitHub или архив). Название
   папки — только латиницей.
2. Нужен Python 3.10+. Проверка: `py --version`.
3. Создайте окружение и зависимости:
   ```bash
   py -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
4. Запуск: `.venv\Scripts\python app.py` → http://127.0.0.1:5000
5. Проверка работоспособности: на главной введите запрос
   «навязчивый детектив с юмором, но не Кинг», нажмите «Подобрать книги».
   В ответе — 5 карточек; после запроса на главной появилась «История
   дегустаций» с этой записью.

## Проверка после установки (чек-лист)

- GET http://127.0.0.1:5000/ — главная с формой (HTTP 200)
- POST /select с текстом запроса — страница-подборка с карточками
- Ссылки «Проверить в Яндекс Книгах» открывают поиск по названию+автору
- `/history/<id>` открывает старую подборку; несуществующий id — 404
- Пустой запрос → страница «Дегустация не удалась» с подсказкой

## Как устроен код

- `app.py` — маршруты Flask; полный конвейер (вкус → поиск → отбор)
  выполняется в `POST /select`.
- `sommelier/llm.py` — обёртка над Pollinations: без ключа работает на
  `text.pollinations.ai` и соблюдает лимит 1 запрос в 30 сек
  (`_FREE_WINDOW`); с переменной окружения `POLLINATIONS_API_KEY` уходит
  на `gen.pollinations.ai` без лимитов.
- `sommelier/taste.py` — шаг 1: запрос → JSON-признаки вкуса
  (genres, themes, keywords_en, avoid, note_ru).
- `sommelier/search.py` — шаг 2: кандидаты из двух каталогов; сбой одного
  каталога не останавливает подборку. Опциональный
  `GOOGLE_BOOKS_API_KEY` снимает дневную квоту.
- `sommelier/curate.py` — шаг 3: модель отбирает по индексам кандидатов
  (нельзя «выдумать» книгу) и пишет why / vibe_like / caveat.
- `sommelier/db.py` — SQLite (таблица `requests`), история подборок.
- `config.py` — модель, таймауты, лимиты, размер подборки.

## Нюансы бесплатного режима Pollinations

- только модель `openai-fast` (gpt-oss-20b);
- 1 запрос в 30 сек — LLM-вызовов в конвейере два, подборка занимает
  ~1 минуту; `POST /select` отдаёт страницу прогресса потоковым ответом
  (Flask generator + `<script>`-вставки в `templates/progress.html`),
  так что пользователь видит живые этапы, а не висящий экран;
- ответ модели обрезается на ~1500 токенов — отбор компактный
  (3–5 книг, короткие обоснования) и в запросе стоит
  `reasoning_effort: low`, чтобы «размышления» не съедали лимит;
- для шага «отбор» включён `response_format: json_object` (дисциплинирует
  схему), для шага «вкуса» — обычный режим: с `json_object` модель
  выдавала только первый ключ объекта;
- `render_template` нельзя вызывать внутри стримящегося генератора
  (нет app-context) — скелет страницы прогресса рендерится заранее.

## Типовые доработки

- Портрет вкуса по истории: таблица `requests` уже хранит `taste`; добавить
  кнопку оценки («в точку»/«не то») в `result.html` и колонку `rating` в
  `sommelier/db.py`, затем учитывать оценки в `taste.py`.
- Русскоязычный акцент подборки: с ключом `GOOGLE_BOOKS_API_KEY` добавить
  в `search.py` параметр `langRestrict=ru` для Google Books.
- Экспорт подборки: Jinja-шаблон в PDF/Markdown — карточки уже содержат
  все нужные поля.
